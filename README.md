# ObstacleAssault by VIYUKI

ObstacleAssault is a fast-paced 3d platformer where players must overcome challenging obstacle courses, moving platforms, rotating traps, and precision based jumps to reach the finish line.
The game focuseson movement, timing, and player control through a series of increasingly difficult platforming sections. Each level introduces new obstacles and mechanics that test player's reflex, coordination , and precision

Tools: Unreal Engine v5.0 and Visual Studio 2019 Community

Build and compile using Unreal Engine v5.0+

With the keyboard and mouse: W A S D to move, space to jump, mouse to look around
3d Platform game try to go as high as you can
